# Silvia’s Hair Premium

Site institucional responsivo desenvolvido em React + Vite, pronto para GitHub e Vercel.

## Rodar localmente

1. Instale o Node.js 22 ou mais recente.
2. Execute `npm install`.
3. Execute `npm run dev`.

## Publicar pelo GitHub na Vercel

1. Crie um repositório vazio no GitHub.
2. Envie todo o conteúdo desta pasta para o repositório.
3. Na Vercel, clique em **Add New → Project** e importe o repositório.
4. A Vercel reconhecerá o Vite automaticamente. Mantenha o comando de build `npm run build` e a pasta de saída `dist`.
5. Clique em **Deploy**.

## Editar

- Conteúdo e seções: `src/App.tsx`
- Cores, tipografia e responsividade: `src/styles.css`
- Imagens: `public/salon/`
- Metadados e título: `index.html`

Os links de WhatsApp, telefone, Instagram, Facebook e e-mail estão no arquivo `src/App.tsx`.
